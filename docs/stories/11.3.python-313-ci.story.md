### Context

- **The old blocker is gone.** The locked thinc 8.3.13, spaCy 3.8.14, numpy 2.2.6, srsly 2.5.3, blis 1.3.3, cymem 2.0.13, preshed 3.0.13, murmurhash 1.0.15 and torch 2.13.0 all have cp313 wheels in the lock's own file lists (SM, 2026-11-05).
- **The PySide6 blocker (found by the SM, 2026-11-05).** Every PySide6-Essentials and shiboken6 release from 6.7.0 to 6.8.0.1 declares `Requires-Python <3.13,>=3.9` on PyPI. So does the lock: `poetry.lock` l.3121 and l.3714, markers l.3123 and l.3716. pip honours Requires-Python, so the abi3 wheel tags do not help. The first release that allows 3.13 is 6.8.0.2 (2024-10-24). 6.8.3 is the last 6.8 release: `<3.14,>=3.9`, `requires_dist ['shiboken6==6.8.3']`.
  - At `283e211`, `pyproject.toml` l.42 is `{version = "~6.7.0", optional = true, python = ">=3.11,<3.13"}`, so on 3.13 `[gui]` installs without PySide6.
  - Without PySide6, pytest-qt 4.5.0 (dev group) stops the whole pytest session at start-up: `pytest_configure` calls `qt_api.set_qt_api`, which raises `pytest.UsageError` (`pytestqt/qt_compat.py` l.96-99).
  - Lionel chose to move everyone to 6.8.3.
- **What 6.8.3 changes for users.** Its wheels are `macosx_12_0_universal2` (6.7.3: `macosx_11_0_universal2`), `manylinux_2_28_x86_64`, `manylinux_2_39_aarch64` (6.7.3: `manylinux_2_31_aarch64`) and `win_amd64` (orchestrator's and SM's PyPI readings). The desktop app therefore needs macOS 12 or later. The macOS build runs on `macos-14` (`build-executables.yaml` l.145). The project pinned `~6.7.0` on purpose: `docs/architecture/gui-framework-decision.md` l.188 says to pin a minor version (`"~6.7.0"`), and l.513 says "Pin minor version (`~6.7.0`); test version bumps in CI before upgrading". This story is that tested bump; the decision record stays as written (history).
- **The redundant job.** `ci.yaml` l.66-71 holds two ubuntu-22.04 Python 3.11 jobs, one with coverage, one without. The one without coverage (l.69-71) becomes 3.13 and runs the full suite, GUI included.
- **Downloads** (pypistats, ~180 days, epic l.72): 3.11 = 47, 3.12 = 28, 3.13 = 2, 3.14 = 1.
- **Alert #109** (`gh api repos/LioChanDaYo/RGPDpseudonymizer/dependabot/alerts/109`, SM, 2026-11-05): open, `poetry.lock`, scope `development`, vulnerable `= 1.14.0`, first patched `1.15.0`; "Stanza: RCE via pickle deserialization in the lemmatizer". It is the only open alert.

```python
import subprocess, tomllib
from collections import defaultdict

def index(lock, field):
    out = defaultdict(list)
    for p in lock["package"]:
        out[p["name"].lower()].append(str(p.get(field, "(none)")))
    return {k: " | ".join(sorted(v)) for k, v in out.items()}

old = tomllib.loads(subprocess.run(["git", "show", "283e211:poetry.lock"], capture_output=True, encoding="utf-8", check=True).stdout)
new = tomllib.load(open("poetry.lock", "rb"))
for field in ("version", "python-versions", "markers"):
    o, n = index(old, field), index(new, field)
    for k in sorted(o.keys() | n.keys()):
        if o.get(k) != n.get(k):
            print(f"{field} {k}: {o.get(k, '-')} -> {n.get(k, '-')}")
print("metadata python-versions:", old["metadata"]["python-versions"], "->", new["metadata"]["python-versions"])
```
