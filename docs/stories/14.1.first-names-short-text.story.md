### Context: why a lone first name is missed today

- **The label map drops MISC.** `SpaCyDetector._map_entity_type` (`nlp/spacy_detector.py:194-213`) maps PER, LOC, GPE and ORG (and their long forms); every other label, MISC included, gives `None`, and `detect_entities` keeps only mapped entities (`:169-188`). spaCy's French model often labels a lone first name MISC: 1,507 of QA's 7,390 cases, and 79.9% of the misses (QA, `measure.log` (d)). The Doc is kept (`self._last_doc = doc`, `:166`; `last_doc`, `:237-244`), so a rule can still read the MISC spans.
- **How « Bonjour X, » already reaches PERSON.** Story 10.4's R-SAL-BARE (`hybrid_detector.py:1526-1563`) adds a regex PERSON for a known first name on a salutation line (`_salutation_lines`, `:1310-1359`): shape 1, one or two names alone on a line ending with a comma; shape 2, an opener of `salutations.yaml` (« Bonjour », « Merci », « Bonne initiative », « Félicitations ») then the name and `, . !` or the end of the line. "Known" means `NameDictionary.is_first_name` (`name_dictionary.py:81-91`) over `french_names.json`'s 451 names. So « Bonjour X, » works for those 278 library names that are also in `french_names.json` (0 missed of 278) and not for the 461 others (204 missed); « Merci X pour … » is not a salutation line (a word follows the name), nor is « Cordialement,⏎X » (no comma after the name).
- **The other 20%: spaCy finds nothing** (350 of 1,738 misses; 206 of them in « Réponse de X : »). No MISC rule reaches them; only the cue rule does.
- **What the user sees** (epic): a missed name is not in the desktop review list (`gui/workers/detection_worker.py:167-191`) and can be caught only by selecting it and using « Ajouter comme entité » (`gui/widgets/entity_editor.py:359-367`); if nothing at all was found, the panel says « Aucune entité détectée. Le document ne contient peut-être pas de données personnelles… » and « Continuer ▶ » is still offered (`gui/screens/processing.py:170-174`, `:317-319`).

### The mechanism: CD with the cues Lionel approved (Q1, Q3)

**What it does, in plain words.** spaCy, the language model the app uses, sometimes puts a lone first name in its "other" bucket (MISC), which the app throws away today; sometimes it sees nothing at all. CD has two parts.
- **The "other"-label rule:** when spaCy's "other" bucket holds a capitalised word that is a first name of either list (the default pseudonym library's 739 first names and `french_names.json`'s 451, 898 together, accents ignored, so « Elodie » matches « Élodie »), that word becomes a person. Two guards: a word right after a title (« M. », « Mme », « Dr. ») stays as today, so « M. Bernard » keeps its title; and a word right next to another capitalised word that is not a first name (« Microsoft Azure », « Azure SQL », « Bleu Céleste ») stays as today.
- **The cue rule:** a listed first name becomes a person, with nothing needed from spaCy, when it comes right after « Bonjour », « Merci », « merci », « Salut », « Coucou », « Bonsoir », « Cher », « Chère », « Réponse de », « De la part de », « Envoyé par » or « De : »; when it stands alone on the line after « Cordialement », « cordialement », « Bien cordialement », « Bien Cordialement », « Bien à vous » or « Merci »; or when it follows a dash at the start of a line. It is the only part that reaches the names spaCy does not see (20% of today's misses; 206 of them are « Réponse de X : »), and the chat greetings, where the neighbour guard stops the "other"-label rule. Every word of the cues occurs in the main corpus except the five greetings; the six phrases « Réponse de », « De la part de », « Envoyé par », « Bien cordialement », « Bien Cordialement », « Bien à vous » do not occur as phrases. Lionel approved all eleven under Story 10.3a's rule (Q3 (a) and (b), Decisions Recorded).

   The walk, exactly:
   ```python
   def _line_neighbour(doc: Any, i: int, step: int) -> Any | None:
       """The nearest non-space token before (step -1) or after (step 1)
       token i on the same line; None at a line break or the text's end."""
       j = i + step
       while 0 <= j < len(doc):
           token = doc[j]
           if "\n" in token.text:   # before is_space: spaCy makes a line break a space token
               return None
           if token.is_space:
               j += step
               continue
           return token
       return None
   ```
