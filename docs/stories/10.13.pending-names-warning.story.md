### AC precisions (story-level)

- **AC1, the count, exactly (Fix Design AC1).** For one document:
  - **The list sent.** Batch review: `get_validated_entities()` (`gui/models/validation_state.py:816-818`), the list the batch branch emits (`gui/screens/validation.py:993`, `:996-1000`). Single-document validation: `expand_validated_entities()` (`validation_state.py:820-866`), the list `_start_finalization` hands to the worker (`validation.py:1043`). CLI: the review's `get_validated_entities()` (`validation/models.py:360-387`), plus the names `_run_validation` sends without review because they are known in the mapping database (`core/document_processor.py:333-345`, `:379`).
  - **The places written.** The spans of that list after the overlap rule of `DocumentProcessor._apply_replacements` (`core/document_processor.py:837-843`): sorted by start, the longer first; a span that overlaps one already kept is dropped, and its text is not replaced. The rule applies per cell (the entity's `context_label`; "" outside spreadsheets), as `_apply_tabular_replacements` applies it cell by cell (`:1371-1382`).
  - **A covered place.** One written place contains it entirely: same cell, written start ≤ its start, its end ≤ written end, whatever the types. A written place that only overlaps it does not cover it (T4[partial]). Two written places that cover it only together do not cover it: the epic says "covered by a place", and the characters between them stay (T4[two_pieces]).
  - **A name and its places.** Batch review: the (text, type) of each row still to review, with that row's own span (each place is a row; a batch context carries no variant map, `validation.py:409-419`). Single-document validation: the (text, type) of each row still to review (a row is a name), with its variant occurrences (`_variant_occurrences` under the row's stored key; built at `gui/workers/detection_worker.py:148-164`), else its own span. CLI: each review group of `ValidationSession.get_entity_groups()` (`validation/models.py:427-464`), the entry the user decides or skips with [N], named by its `unique_key` (canonical text, type), with its occurrences still to review.
  - **The count** is the number of different names with at least one place not covered. One name at 2 places counts 1 (T2, T5, T7). Two names still to review at the same place with two types are two names (AC1's "(text and type)").
  - **Two spellings of one person count as 2 in batch review**, and as 1 in single-document validation and in the CLI. Example (PO probe E3): "Zorbalia Quentrix" and "Quentrix" both left gives 2 in batch, where each row is a (text, type), and 1 in the single document (one row) and in the CLI (one review group). This follows AC1's "(text and type)" and is not a bug.
  - **In a spreadsheet the count is per cell** (the CLI's `.xlsx` and `.csv` path): a place is covered only by a written place of the same cell. T10[other_cell] pins it: ORG "Zorbaville" accepted in A1 does not cover LOCATION "Zorbaville" skipped in B1, although both span 0-10 of their cells.
  - A row still to review always holds its detected text, type and span: every desktop action that edits a row also sets its state (`_ModifyTextCommand`, `_ChangeTypeCommand`, `_ChangePseudonymCommand`), and its undo restores both.

### Product Constraints (non-negotiable, verbatim from the epic)

[Source: prd/epic-10-v2.3-detection-precision-quick-wins.md#Product Constraints]

These apply to every story in this epic. A story that cannot meet its goal inside them stops and goes back to Lionel; it does not relax them.

1. **Local NLP only.** No LLM, no generative model, no API call, no cloud service, no telemetry. Every change is a deterministic rule, lexicon or pattern that runs offline.

**AC1, the count: `validation/models.py`** (after `candidate_key`, `:103`; `from collections.abc import Iterable` added to the imports):

```python
# A place in the written file (Story 10.13): (cell, start, end). The cell is
# the entity's ``context_label`` ("" outside spreadsheets); positions are in
# the cell's text, or in the document's text when there is no cell.
Place: TypeAlias = tuple[str, int, int]
NameOfReview: TypeAlias = tuple[str, str]  # (text, type)


def place_of(entity: DetectedEntity) -> Place:
    return (entity.context_label or "", entity.start_pos, entity.end_pos)


def written_places(sent: Iterable[DetectedEntity]) -> list[Place]:
    """The places finalization really replaces (Story 10.13, AC1): the overlap
    rule of DocumentProcessor._apply_replacements, per cell."""
    kept: list[Place] = []
    for cell, start, end in sorted(
        (place_of(entity) for entity in sent), key=lambda p: (p[0], p[1], -p[2])
    ):
        if any(k[0] == cell and not (end <= k[1] or start >= k[2]) for k in kept):
            continue
        kept.append((cell, start, end))
    return kept


def count_names_left_in_clear(
    pending: Iterable[tuple[NameOfReview, Iterable[Place]]],
    sent: Iterable[DetectedEntity],
) -> int:
    """Different names still to review that would be written in clear: a name
    counts once, unless each of its places lies entirely inside one written
    place, under any type."""
    written = written_places(sent)
    names: set[NameOfReview] = set()
    for name, places in pending:
        for cell, start, end in places:
            if not any(w[0] == cell and w[1] <= start and end <= w[2] for w in written):
                names.add(name)
                break
    return len(names)
```

The sort mirrors `_apply_replacements`' `sorted(replacements, key=lambda x: (x[0], -x[1]))` with the cell first, so each cell is handled as `_apply_tabular_replacements` handles it. Docstrings name Story 10.13 and Lionel's decision (2026-10-16), as the prototype's do.

```python
def names_left_in_clear(self, sent: list[DetectedEntity]) -> int:
    pending: list[tuple[NameOfReview, list[Place]]] = []
    for review in self._session._entity_reviews:
        if review.state != EntityReviewState.PENDING:
            continue
        key = self._variant_key(review, review.entity)
        occurrences = self._variant_occurrences.get(key, [review.entity])
        name = (review.entity.text, review.entity.entity_type)
        pending.append((name, [place_of(o) for o in occurrences]))
    return count_names_left_in_clear(pending, sent)
```
