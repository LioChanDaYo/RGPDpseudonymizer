## Acceptance Criteria

AC1 to AC11 follow the epic's acceptance (1 to 11, in that order). AC12 to AC14 are story-level. Each AC names its check, run on the final head unless it says otherwise. Where a candidate changes an AC, the AC says "if A…", "if B…"; the version that writes in Lionel's Q1 keeps only his candidate's branch.

1. **AC1: Every row matches what is written, on every path and format.**
   - For every path (desktop single, desktop batch, command line `process` and `batch` with review) and every format (text, PDF and DOCX inputs, which are written as text; CSV and XLSX in the command line, resolved per cell; spreadsheets in the desktop app, read as one text), every row that shows a pseudonym as written has it written at each of its places the row claims, and no two rows claim the same text.
   - **If A:** a detection the end would not write if every row were accepted is never a row or a place of a row (`written_mask` over every detection, in the order the end receives them, before the review).
   - **If B:** a row none of whose places the end would write, given the decisions taken, is marked N1 (desktop) or C1 (command line); a row some of whose places are not written is marked N2 or C2, with the counts; the mark is computed with the end's own function over the list the end would receive (Fix design B).
