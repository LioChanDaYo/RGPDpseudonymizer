### Changes Since the Gate (at `b2042c7`)

- **Story 10.7 changed the shared helper on purpose.** `_assert_winner_db` now asserts `schema_version` "1.1.0" (DB `:58-59`, comment citing 10.7 AC3), not "1.0.0" as the 10.5 Test Plan wrote. The four metadata keys are unchanged. AC2's "metadata intact" is still asserted, against the current schema version.
- **The #83 test** `test_init_database_index_creation_idempotent` stays removed, replaced by T1 (gate `tests_review`).
- **Two tests are POSIX-only by design:** T6 and T8 carry `skipif(sys.platform == "win32")`. On Windows the held descriptor makes T6's replacement impossible (the gate's Windows probe: `PermissionError` [WinError 32], first database kept 30/30). This is the documented behaviour, not a gap.

### Critical Gaps

None.

### Residual Risk (documented in the story, not ACs)

- An interrupt in the few bytecodes right after the exclusive create can leave a 0-byte file. QA's 200 real Ctrl+C runs never hit it (gate `changelog`).
- The window between the identity check and the delete (microseconds) is documented in the story's "Known residuals". Neither deletes a database.

### Risk Assessment

- **High:** none.
- **Medium:** none.
- **Low:** the two POSIX-only tests leave Windows covered by T1, T3-T5, T7, T9 and T10 plus the gate's Windows probes.
