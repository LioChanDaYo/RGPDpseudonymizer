# Story 10.1: Annotation Change Log (AC4)

Repair of the 25 main-corpus annotation files under `tests/test_corpus/annotations/GUIDELINES.md` (approved by Lionel on 2026-10-02, STOP A). Every edit cites one rule ID. The format follows the story's Dev Notes "Change Log Format".

How the list was produced: each document was read end to end. The entities found were listed by hand per document (PERSON, ORG, LOCATION, with the rule that applies), and the list was applied to every exact occurrence in all 25 texts; that application is the string-consistency sweep (3.4 ii). Old and new annotations were then diffed by offsets. **Corrected** means the old span overlaps a new span of the same type. **Removed** means the old span has no same-type successor; a span that only changed type counts as removed + added. **Added** means the new span has no old same-type predecessor. Each annotation is counted once. The F3 bucket is the `size.py` `gt_trunc` heuristic (hyphen-adjacent / ends with ", Word"), first matching bucket.
